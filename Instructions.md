Design Thinking skills for agents, claude code and other CLI tools. 


Problem: 
Solo Devs and Small teams are using AI to build apps and solutions at a super fast pace, often products are not user centered/human centered, because AI has lost context of that. 

Solution: 
We give design thinking skills to AI agents, which can then ask creators for their artifacts, questions, doubts and ideas - Making sure the product they build is user centered and grounded in some sort of research. 

The three approaches to design thinking: 
1. EDIPT 
2. Double Diamond Process 
3. Problem or Opportunity definition followed by constant feedback loop of user feedback and user ideation. 


There are multiple design thinking skills on the market and more are popping up. How do we differ?

We write pre PRD skills 

Pre-Planning → PRD → UX Doc → Prompts → Code → Evaluate
